# CodeAlpha Cyber Security Internship — Task 2 Report

## Title
Phishing Awareness Training

## Objective
Create an online module focused on phishing attacks and teach users how to recognize phishing emails, fake websites, and social engineering tactics.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
1. Introduction to phishing.
2. Phishing email warning signs.
3. Fake website detection guidance.
4. Social engineering tactics.
5. Three realistic fictional examples.
6. Best practices for avoiding phishing.
7. Five-question interactive quiz.
8. Automatic score and feedback.
9. Responsive browser layout.

## Working
The user opens `index.html`. Training sections explain phishing indicators and safe actions. The quiz uses radio buttons. JavaScript checks the selected answers against predefined correct answers and displays the score.

## Security and Ethics
This is an awareness-only project. It does not collect credentials, create real phishing pages, send phishing emails, or target real users.

## Testing
- `index.html` opens successfully in a browser.
- All correct answers produce 5/5.
- Mixed answers produce the corresponding score.
- Unanswered questions count as incorrect.
- The layout adapts to smaller screens.

## Learning Outcomes
- Identified common phishing indicators.
- Learned social engineering tactics.
- Learned why the actual domain should be checked.
- Practiced safe responses to suspicious messages.
- Implemented a JavaScript quiz.

## Conclusion
The module combines educational content, examples, safety practices, and an interactive quiz to improve phishing awareness.
