# CodeAlpha Task 2 — Phishing Awareness Training

An interactive browser-based phishing awareness training module created for the CodeAlpha Cyber Security Internship Task 2.

## Requirements Covered
- Phishing attacks
- Recognizing phishing emails and fake websites
- Social engineering tactics
- Best practices and safety tips
- Real-world-style examples
- Interactive quiz

## Technologies
HTML5, CSS3, JavaScript

## Run
Open `index.html` in any modern web browser. No server is required.

## Files
- `index.html` — training content and quiz
- `style.css` — styling and responsive layout
- `script.js` — quiz scoring
- `REPORT.md` — project report
- `sample_quiz_output.txt` — sample result
- `.gitignore` — Git ignore rules

## Safe Demonstration
The examples are fictionalized. This project does not create phishing pages, collect credentials, or send phishing messages.
